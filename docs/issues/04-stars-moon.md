## 目的
星と月の光輪を、ゆっくり脈打つように光らせる。

## やること
- `docs/DESIGN.md` の「星と月」に従う
- 星と月の位置・光輪の半径を、実際の絵を見て `src/logic/stars.ts` に定義する(月 + 星 11 個ほど)
- 星ごとに周期(数秒)と位相をずらし、明るさを ±10% 程度で変える。白飛びさせない
- 光輪のまわりに、ごく弱い回転の流れを加える(#3 の流れ場に足す)
- テスト: 明るさの倍率が常に 0.9〜1.1 に収まる、星ごとに位相が異なる

## 受け入れ条件
- [ ] `npm run typecheck && npm test && npm run build` が通る
- [ ] 星と月が、それぞれ少しずつ違うリズムで静かに瞬いて見える
- [ ] 1画素あたりのテクスチャ読み込みが 4 回以内
