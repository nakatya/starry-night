## 目的
動かしてよい範囲(空)を決めるマスクをコードで生成する。

## やること
- `docs/DESIGN.md` の「空のマスク」に従う。地平線の曲線と糸杉の形を、点の列(絵の割合座標)として `src/logic/mask.ts` に定義する
- 実際の絵(`public/starry-night.jpg`)を見て、点の位置を合わせる
- マスクは起動時に一度だけ生成してテクスチャにする(Canvas 2D で塗ってぼかす、またはシェーダーで計算する。どちらでもよい)。毎フレーム生成しない
- 境界は数 px ぶんぼかす
- `?debug=mask` でマスクを白黒で絵に重ねて表示する
- テスト: 空の中の点(例: 中央の渦の中心)が 1、村の点(例: 0.6, 0.85)と糸杉の点(例: 0.15, 0.6)が 0 になること

## 受け入れ条件
- [ ] `npm run typecheck && npm test && npm run build` が通る
- [ ] `?debug=mask` で見ると、空だけが白く、糸杉・丘・村が黒くなっている
- [ ] 通常表示の見た目は #1 と変わらない
