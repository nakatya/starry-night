## 目的
空のうねりを、筆の流れに沿ってゆっくり動かす。このサイトの要。

## やること
- `docs/DESIGN.md` の「うねりの動かし方(フローマップ方式)」に従う
- `src/logic/flow.ts`: 渦の定義(中心・半径・強さ・向き)と、空全体の流れを定義し、`flow(u, v)` を返す純粋関数を作る。シェーダーにも同じ値を uniform で渡す
- 実際の絵を見て、渦の中心と巻く向きを筆の流れに合わせる
- シェーダー: 2つの位相を半周期ずらして重ねるフローマップ方式。マスクが 0 の場所は動かさない
- 1周期 約 8 秒、最大のずれは絵の幅の 0.6% 程度
- `?speed=` で速さの倍率を変えられる(既定 1)
- テスト: 渦の中心から半径の外では流れがほぼ 0、渦の中では流れが中心まわりの接線方向を向く、ずれの大きさが上限を超えない

## 受け入れ条件
- [ ] `npm run typecheck && npm test && npm run build` が通る
- [ ] 空の渦が、筆の流れに沿って回っているように見える。絵が崩れたり、ちらついたり、周期ごとにガクッと戻ったりしない
- [ ] 糸杉・丘・村は動かない。境界に継ぎ目が見えない
- [ ] 人の確認が必要: 動きの速さと強さが「ゆっくり、静か」か
