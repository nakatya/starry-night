# デザイン仕様

## 目指すもの
ゴッホ「星月夜」の全体が画面に映り、**空だけ**が、筆の流れに沿ってゆっくりうねり続ける。
糸杉・丘・村は動かない。絵そのものを壊さず、「絵が呼吸している」ように見えることがゴール。
操作は不要。開いたらすぐ絵が出て、動き続ける。

## 表示
- 絵は**全体が見えるように**画面の中央に収める(CSS の `object-fit: contain` と同じ考え方)。縦横比は崩さず、切り落とさない。
- 絵の外側に余る部分には、画面を覆うように拡大した同じ絵を、ぼかして暗く(3 割程度の明るさ)敷く。黒帯にはしない。
- 画面サイズや向きが変わったら、すぐに描き直す。
- 解像度は `devicePixelRatio` に合わせる。ただし上限 2。
- スクロールバー、余白、UI は出さない。右下に小さく「Vincent van Gogh, The Starry Night (1889)」とだけ表示する(半透明、小さい文字、邪魔にならない程度)。

## 空のマスク
- 動かす範囲を決めるマスクを、**コードで**生成する(画像素材は追加しない)。
- 空 = 1、糸杉・丘・村 = 0。境界は数 px ぶんぼかし、動く部分と動かない部分の継ぎ目が見えないようにする。
- 形はおおよそ次のとおり。正確な位置は実際の絵を見て合わせる。
  - 地平線(丘の稜線): 絵の縦 0.55〜0.68 あたりを左右に走るゆるい曲線。これより下は動かさない。
  - 糸杉: 絵の左端、横 0.05〜0.28、下端から縦 0.0 付近まで炎のように伸びる。全体を動かさない。
- `?debug=mask` を付けて開くと、マスクを白黒で重ねて表示できるようにする(確認用)。

## うねりの動かし方(フローマップ方式)
絵の画素そのものを流れに沿ってずらして見せる。ずれが積み重なって絵が崩れないよう、**2つの位相を交互に重ねる**フローマップ方式にする。

- 各点の流れの向き `flow(uv)` を、次の合計で作る。
  1. 渦: 絵の中の渦の中心のまわりを回る流れ。中心からの距離で弱まる(半径の外ではほぼ 0)。
  2. 空全体の流れ: 中央を左から右へ横切る大きな波の帯に沿った、ゆるい横向きの流れ。
  3. 星と月のまわり: 光輪に沿った、ごく弱い回転。
- 渦の目安(実際の絵を見て合わせてよい。合わせた値は `src/logic/` に定義する):
  - 中央の大きな二重の渦: 中心 (0.47, 0.33)、半径 0.13
  - その左上の小さめの渦: 中心 (0.30, 0.24)、半径 0.08
  - 回る向きは、絵の筆の流れ(渦巻きの巻き方)に合わせる
- シェーダーでは、`uv - flow(uv) * 位相` で絵を2回読み、位相を半周期ずらした2つを三角形の重みで混ぜる(よくある水面のフローマップと同じ手法)。
- 動きの強さと速さの目安:
  - 1周期: 約 8 秒
  - 最大のずれ: 絵の幅の 3% 程度(0.6% では画素が数 px 行き来するだけで、動いて見えなかった)
  - 全体として「ゆっくり、静かに」。目が疲れたり、酔ったりしない速さにする
- マスクが 0 の場所では流れも 0 にする(動かない)。
- `?speed=1.5` のように URL で速さの倍率を変えられるようにする(確認用。既定は 1)。
- `?amp=0.5` のように URL で動きの大きさの倍率を変えられるようにする(確認用。既定は 1、上限 3)。

## 星と月
- 星と月のまわりの光輪(同心円状の光)を、ゆっくり明るさが脈打つように見せる(数秒周期、星ごとに少しずつ周期と位相をずらす)。
- 明るさの変化は控えめに(元の明るさの ±10% 程度)。白飛びさせない。
- 星の位置は実際の絵を見て `src/logic/` に定義する(月 + 星 11 個ほど)。

## 配慮と性能
- `prefers-reduced-motion: reduce` のときは動かさず、静止した絵だけを表示する。
- タブが見えないとき(`document.hidden`)は描画を止める。
- スマホでも 60fps を目指す。シェーダーの読み込み回数を増やしすぎない(1画素あたりテクスチャ読み込みはおおむね 4 回以内)。
- WebGL が使えないときは、CSS の背景画像(`background-size: contain`、中央)で静止画を表示する。
- 読み込み中は黒い画面にし、画像の準備ができたらふわっと(0.8 秒ほど)フェードインする。
